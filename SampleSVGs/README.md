# Sample SVG Files

Dieser Ordner enthält Beispiel-SVG-Dateien zum Testen der WinUI SVG Viewer Applikation.

## Enthaltene Dateien

1. **happy_face.svg** - Ein einfaches Smiley-Gesicht
   - Demonstriert: Kreise, Pfade, Text

2. **geometric_shapes.svg** - Verschiedene geometrische Formen
   - Demonstriert: Rechtecke, Kreise, Polygone mit verschiedenen Farben

3. **gradient_example.svg** - Beispiel mit Farbverläufen
   - Demonstriert: Linear Gradient, Transparenz, verschachtelte Elemente

## Verwendung

1. Starten Sie die WinUI SVG Viewer Applikation
2. Klicken Sie auf "Select Folder"
3. Wählen Sie diesen "SampleSVGs" Ordner aus
4. Die SVG-Dateien werden in der Liste angezeigt
5. Klicken Sie auf eine Datei, um sie anzuzeigen

## Eigene SVG-Dateien hinzufügen

Sie können beliebige SVG-Dateien in diesen Ordner kopieren, um sie in der Applikation anzuzeigen. Die Applikation unterstützt alle Standard-SVG-Features, die von Svg.Skia gerendert werden können.
